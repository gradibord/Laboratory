# ∇ GRADIBORD | Laboratory
> **Where Theory Meets Critical Control.**

Welcome to the central research and development hub of **GRADIBORD s.r.o.** This repository serves as an open laboratory for exploring the boundaries of formal verification, gradient-based optimization, and safe autonomous navigation.

---

## 🔬 Mission
Our goal is to transform "Black Box" AI into a transparent, deterministically safe system. We focus on bridging the gap between high-level machine learning and low-level control theory.

## 🛠 Active Research Areas
- **Safe-Gradient Navigation (SGN):** Implementing Control Barrier Functions (CBF) within JAX-based optimization loops.
- **Formal Verification:** Exploring Interval Bound Propagation and reachability analysis for neural networks.
- **Embedded Optimization:** Benchmarking JIT-compiled control loops for real-time deployment.
